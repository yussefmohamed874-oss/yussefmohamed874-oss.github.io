# قالب فيديو جديد (انسخه والصقه مع الفيديو الجديد)

اتبع `.claude/CLAUDE.md` و`.claude/ref/brief.md` بالكامل. هذا فيديو جديد بنفس أسلوب «مقاومة الأكل وأنت متعصب».

- **الموضوع:** ...
- **الفيديو الخام (أو اللقطات):** مرفقة (الترتيب: ...)
- **النص الحرفي (من الدكتور، لا يُغيَّر):**
  ```
  ...
  ```
- **الإنترو والأوتّرو:** نفس الملفين المرسلين سابقاً (أو مرفقان بجانب هذا).
- **لقطات جيميناي / الكوميديا:** مرفقة، أو اكتب لي برومتاتها (لقطتان لكل فيديو 10 ثواني) حسب النص.
- **تعديلات خاصة:** ...

المطلوب منك: (1) مراجعة المرفقات والأسئلة الناقصة، (2) خطة المشاهد للموافقة، (3) لا مونتاج نهائي قبل موافقتي.
